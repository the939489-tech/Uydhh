# AL Store Games
واجهة متجر ألعاب Gaming جاهزة كبداية.

## أهم أماكن التعديل
- `js/config.js`: رقم واتساب وبيانات التحويل.
- `js/products.js`: الأقسام والمنتجات والأسعار والصور.
- `assets/banners/`: صور الـ Hero.
- `assets/products/`: صور المنتجات.
- `css/style.css`: كل التصميم والـ animations.

## التشغيل
افتح `index.html` في المتصفح. يمكن استبدال صور الـ SVG بصور حقيقية بنفس الأسماء/تحديث المسارات في ملفات JS.
